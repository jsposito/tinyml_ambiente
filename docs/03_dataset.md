# Dataset do Projeto

## 1. Finalidade

O dataset será utilizado para treinar e avaliar o modelo de classificação ambiental.

Cada registro será formado por três variáveis de entrada:

- temperatura;
- umidade;
- luminosidade.

Cada registro terá dois rótulos independentes:

- condição térmica;
- condição de iluminação.
